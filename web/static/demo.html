Support Chat Widget Demo

This page demonstrates the embedded support chat widget. Click the chat button in the bottom-right corner to start.

Integration Instructions


// Add to your HTML head
<script src="https://your-server.com/static/chat-widget.js"></script>

// Initialize the widget
const supportChat = new SupportChatWidget({
    serverUrl: 'https://your-server.com',
    title: 'Support Chat',
    placeholder: 'Type your message...',
    position: 'right',
    theme: 'light'
});
